# 🧀 queso: arm32 disassembler

queso is a arm32 disassembler written in golang. I originally wrote this to interop with my emulation projects, allowing for easier debugging.

# Features
- Supports Arm and Thumb instructions
- Supports Big and Little Endian
- Supports General and Convention Register Names (r15 vs pc) (and Custom!)
- Supports Standard and Stack Block Instruction Suffixes (ldmia vs ldmed)
- Supports Hex and Decimal Base Immediate Values

# Notes
- Uses Unified Assembler Language (UAL) syntax
- Speed is roughly 50 million instructions per second (something something on my machine something something)
